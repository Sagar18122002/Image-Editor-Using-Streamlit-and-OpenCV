# 🖼️ Image Editing App with Streamlit & OpenCV

## 📌 Project Overview

This project is a browser-based Image Editing Application built using **Python, Streamlit, and OpenCV**.  
The application allows users to upload images and apply multiple image processing filters in real time through an interactive web interface.

The project demonstrates practical implementation of image processing techniques using OpenCV along with an easy-to-use Streamlit UI.

---

# 🚀 Features

✅ Upload JPG, JPEG, and PNG images  
✅ Apply Blur Filter  
✅ Adjust Sharpness  
✅ Modify Brightness  
✅ Adjust Contrast  
✅ Edge Detection using Canny Algorithm  
✅ Convert Image to Grayscale  
✅ Real-Time Image Preview  
✅ Download Processed Image  
✅ Interactive Sidebar Controls  
✅ Stackable Filters

# ⚙️ Installation

## Step 1: Clone Repository

```bash
git clone https://github.com/your-username/Image-Editor-Using-Streamlit-and-OpenCV.git
```

## Step 2: Navigate to Project Folder

```bash
cd Image-Editor-Using-Streamlit-and-OpenCV
```

## Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
streamlit run app.py
```

After running the command, the application will open automatically in your browser.

# 🎛️ Filters Implemented

| Filter | Description |
|--------|-------------|
| Blur | Smooths the image using Gaussian Blur |
| Sharpness | Enhances image details |
| Brightness | Increases or decreases brightness |
| Contrast | Adjusts image contrast |
| Edge Detection | Detects edges using Canny algorithm |
| Grayscale | Converts image to grayscale |
